Research a topic using NotebookLM and create content from findings.

Topic: $ARGUMENTS

Steps:
1. Use notebooklm_create to create a notebook titled with the topic
2. Search the web to find 3-5 high-quality sources, then add them (or use sources provided by user)
3. Use notebooklm_query to extract key insights, data points, and quotable facts
4. Use notebooklm_generate to create a summary
5. Present findings and ask the user what to do next:
   - Create social posts from the research
   - Build a week-long content plan from it
   - Just deliver the research brief
