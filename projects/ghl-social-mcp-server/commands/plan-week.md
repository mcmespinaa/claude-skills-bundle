Plan a 7-day social media content calendar.

Topics/themes: $ARGUMENTS

Steps:
1. Use get_accounts to find all connected social accounts
2. Use get_next_slot to find the first available posting slot
3. For each of the 7 days, create:
   - A content theme/angle tied to one of the topics
   - Platform-specific captions for each connected account
   - A visual concept description for image generation
   - The scheduled time (space posts 24 hours apart)
4. Validate every caption with validate_caption
5. Present the full calendar for review before scheduling
6. On approval, use create_post to schedule each post

Writing rules:
- No em dashes (use commas or ...)
- No hashtags (exception: 3-5 on carousel posts)
- Active voice, short sentences
- Emoji limits: X 0-2, LinkedIn 1-2, Facebook 1-3, Instagram 2-4, Threads 0-2
- Avoid AI-sounding words (delve, leverage, paradigm, etc.)
