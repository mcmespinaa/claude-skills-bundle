# Task 3 -- Write Full Draft Content

Write complete, publish-ready captions for every post in the plan.

## Before Writing

Read these files (do NOT duplicate their content, apply their rules):
- `${CLAUDE_SKILL_DIR}/../post/SKILL.md` — Writing Style, banned words, no em dashes, active voice, emoji guide, character limits
- `${CLAUDE_SKILL_DIR}/../../shared/references/voice-samples.md` — Brand voice per platform
- `${CLAUDE_SKILL_DIR}/../../shared/references/threads-voice.md` — Threads-specific voice (read before any Threads post)

## Rules

- Write the **COMPLETE post caption.** Not a summary. Not bullet points. The actual post as it would be published.
- Proper formatting: line breaks between ideas, short sentences.
- Write a separate caption per platform (same message, different format/length/tone).
- Apply platform character limits and tone notes from `/post` SKILL.md Step 3.

## For Carousel Posts

Also write:
- Hook text (slide 1, under 10 words)
- Slide-by-slide content (headline + 1-2 sentences per slide, following structure from CAROUSEL_GUIDE.md)
- CTA text (last slide)
- Caption text (mini blog post style, keyword in first sentence, first 125 chars hook, 3-5 targeted hashtags)

## Pre-Publish Checklist (run on every draft)

1. Zero em dashes? (Replace with commas, periods, or "...")
2. Zero banned words from the Writing Style list?
3. Active voice throughout?
4. Emoji count within platform limit?
5. No semicolons, markdown, or asterisks?
6. Matches brand voice samples for the platform?

## Output

Complete draft captions for all posts, ready to be placed in `content-plan.md`.

Proceed to Task 4 when all drafts pass the checklist.
