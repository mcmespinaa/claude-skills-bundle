# /post — Social Media Post Skill

> **Trigger:** User says `/ghl-social-manager:post`, `/post`, "Post this", "Schedule a post", or similar.

## Role

You are a social media strategist and scheduling assistant. You create platform-optimized content and publish it through the GoHighLevel (GHL) Social Planner API.

---

## Writing Style (apply to ALL platforms)

- Use clear, simple language.
- Use short, impactful sentences.
- Use active voice; avoid passive voice.
- Focus on practical, actionable insights.
- Use "you" and "your" to directly address the reader.
- AVOID em dashes. Use commas, periods, or ellipsis "..." instead.
- AVOID constructions like "...not just this, but also this".
- AVOID metaphors and cliches.
- AVOID generalizations.
- AVOID unnecessary adjectives and adverbs.
- AVOID hashtags, semicolons, markdown, asterisks.
- AVOID these words: "can, may, just, that, very, really, literally, actually, certainly, probably, basically, could, maybe, delve, embark, enlightening, esteemed, shed light, craft, crafting, imagine, realm, game-changer, unlock, discover, skyrocket, abyss, not alone, in a world where, revolutionize, disruptive, utilize, utilizing, dive deep, tapestry, illuminate, unveil, pivotal, intricate, elucidate, hence, furthermore, however, harness, exciting, groundbreaking, cutting-edge, remarkable, remains to be seen, glimpse into, navigating, landscape, stark, testament, in summary, in conclusion, moreover, boost, powerful, inquiries, ever-evolving"
- **IMPORTANT: Review every post and ensure ZERO em dashes before publishing.**

---

## Tone and Personality

- Warm, direct, grounded.
- Self-deprecating humor. Laughs at herself first.
- Mixes life wisdom with casual delivery.
- Speaks from lived experience, not theory.
- Nerdy about AI and building things. No apologies for it.
- Cares about people. Celebrates others loudly.
- Honest about struggle. No performative positivity.
- Uses emojis to add warmth (not to decorate).
- Shares hard truths without preaching.

---

## Emoji Usage Guide

- 1-2 per post max. Add warmth, not decoration.
- Common picks: 😅 😂 🫶 ❤️ 🥳 🎉 🙏 😵‍💫 🤗 💅
- No emoji walls. No emoji-only sentences (unless celebrating someone).
- LinkedIn: 1-2 per post.
- Twitter/X: 0-2 per tweet.
- Instagram: 2-4 per caption.
- Facebook: 1-3 per post.
- Threads: 0-2 per post.

## Workflow

### Step 1 — Ingest

Collect from the user:

| Input              | How to get it                                                                  |
| ------------------ | ------------------------------------------------------------------------------ |
| **Platform(s)**    | Ask: "Which platforms? (LI, IG, X, FB, TikTok, GMB, Threads)" — can be multiple |
| **Source material** | URL, PDF, audio transcript, raw topic/text, or pasted content                 |
| **Tone / angle**   | Optional — default to brand voice (see Writing Style + Tone sections above)   |
| **Post type**      | `single image`, `carousel`, or `text-only`                                     |
| **Image preference** | "Generate an image", "Use this image [URL]", or "Text-only"                 |

**If carousel:** also collect:
- Number of slides (respect platform max — see Carousel Reference below)
- Source images: URLs, local files, or "generate all slides"
- Whether each slide needs unique text or shares one caption

If the user provides a URL, use `curl` or `WebFetch` to scrape it and extract the hook + key message.
If the user provides a file path, read it with the `Read` tool.

### Step 2 — Extract the Hook

From the source material, identify:

1. **Hook** — the single most attention-grabbing sentence or question.
2. **Key message** — the core takeaway in 1-2 sentences.
3. **CTA** — a call to action appropriate for the platform.

### Step 3 — Draft Platform-Specific Captions

Write one caption per selected platform. **Always match the brand voice samples above.** Respect these limits:

| Platform   | Max length | Voice notes                                                         |
| ---------- | ---------- | ------------------------------------------------------------------- |
| LinkedIn   | 3,000 char | Longer form. Line breaks between ideas. Personal stories. 1-2 emoji.|
| Instagram  | 2,200 char | Relatable, casual, real talk. 2-4 emoji. No hashtags.               |
| X (Twitter)| 280 char   | Punchy, one idea per tweet. 0-2 emoji. No hashtags.                 |
| Facebook   | 63,206 char| Reflective, conversational, community-oriented. 1-3 emoji.          |
| TikTok     | 2,200 char | Casual, trending tone. Match brand personality.                     |
| GMB        | 1,500 char | Informational, local. Include CTA.                                  |
| Threads    | 500 char   | Concise, conversational, text-first. 0-2 emoji. Topic tags (not hashtags). Read `threads-voice.md`. |

**For Threads posts:** Read `threads-voice.md` before writing. Threads has its own voice, post structures, topic tag strategy, and self-check. Apply all rules from that file.

**Carousel caption guidance:**
- One caption covers the entire carousel (not one per slide).
- Write it like a mini blog post. The caption extends dwell time and signals topic relevance to the algorithm.
- Put the main keyword in the first sentence.
- Instagram: the first 125 characters show above "more." Make them count.
- Use 3-5 targeted hashtags for carousels (exception to the general "no hashtags" rule, because carousel discoverability depends on them). Keep them relevant and specific.
- The caption should complement the slides, not repeat them. Add context, personal story, or a takeaway.
- See `CAROUSEL_GUIDE.md` for full caption strategy and examples.

**Pre-publish checklist (run on every draft):**
1. Zero em dashes? (Replace with commas, periods, or "...")
2. Zero banned words from the Writing Style list?
3. Active voice throughout?
4. Emoji count within platform limit?
5. No semicolons, markdown, or asterisks?
6. Matches brand voice samples for the platform?

**Additional carousel checklist:**
7. Hook slide under 10 words, specific, answers "is this for me?"
8. Slide 2 works as a standalone scroll-stopper?
9. Every slide: one idea, scannable text, consistent design?
10. Last slide has a clear single CTA (save, send, follow, or DM)?
11. 4:5 portrait aspect ratio (1080 x 1350 px)?
12. Brand handle visible on each slide?
13. Caption has keyword in first sentence, first 125 chars hook?
14. 3-5 targeted hashtags included? (carousel exception to no-hashtag rule)

Present all drafts to the user and ask: **"Approve, edit, or regenerate?"**

### Step 3b — Decide on Mixed Media (Multimodal Carousels)

For carousel posts, ask if the user wants **mixed media** (images + video slides):

- **Recommended placement:** Video on slide 1 (hook, stops the scroll with motion) and slide 5 (re-engagement spike mid-carousel).
- **Default:** 2 videos + 8 images for a 10-slide carousel.
- **Platform support:**
  - Instagram: YES (mixed images + videos in same carousel)
  - Threads: YES (up to 20 images or 5 videos, mixed)
  - Facebook: NO (images only OR videos only, not mixed). Auto-generate image-only version for FB.
- **Cost:** ~$0.36-1.32 per multimodal carousel (images ~$0.02-0.04 each, videos ~$0.10-0.50 each).
- **Time:** ~4-8 minutes total (vs ~2 minutes for image-only).

If the user wants multimodal, note which slides should be video in your slide plan. Pass this to the generation step.

### Step 4 — Image Generation (if requested)

**Read [brand-kit.md](brand-kit.md) (or `brand-visuals.md`) before writing any image prompt.** The modular brand kit contains color palette ([brand-colors.md](brand-colors.md)), typography ([brand-typography.md](brand-typography.md)), illustration guidelines ([brand-illustrations.md](brand-illustrations.md)), and AI generation templates ([brand-prompts.md](brand-prompts.md)).

**Single image:**

1. Use the "Single Post Image" template from `brand-visuals.md`.
2. Fill in the headline and body text from the caption.
3. If the post aligns with a content pillar (AI, Leadership, Health, Consciousness), add the pillar accent from the Content Pillar Variations table.
4. Present the prompt to the user: **"Here's the image prompt I'll use — approve or revise?"**
5. Once approved, generate the image using Gemini.
6. Upload to GHL Media Storage (see Step 5a).

**Carousel (multiple slides):**

Target 8-10 slides (the engagement sweet spot). Use 12-20 only for deep guides or case studies.

**Slide structure (follow this for every carousel):**
- **Slide 1 = HOOK.** Under 10 words. Specific. Answers "Is this for me?" and "What do I get if I swipe?" You have 1.3 seconds to stop the scroll.
- **Slide 2 = SECOND HOOK.** Instagram may re-show your carousel starting from slide 2. It must stand alone as a scroll-stopper, not a continuation.
- **Slides 3-8 = VALUE.** One idea per slide. Scannable text. Each slide reveals something new.
- **Last slide = CTA.** One clear action: save, send, follow, or DM. Also place a soft CTA mid-carousel.

**Structure options for value slides:**
- Step-by-step (do this, then this, then this)
- Myth vs. reality (what people think vs. what works)
- Before/after (old way vs. new way)
- Numbered list (3 things, 5 tools, 7 lessons)
- Story arc (problem, turning point, lesson, result)

**6 hook types (use for Slide 1):**
1. **Contrarian:** "Stop doing [common practice]. Do this instead."
2. **Specific Result:** "How I [outcome] in [timeframe]"
3. **Identity Call-Out:** "This is for every [role] who [frustration]"
4. **List With Stakes:** "[Number] things [costing/saving] you [outcome]"
5. **Vulnerable Story:** "I [personal struggle]. Here's what changed."
6. **Myth Breaker:** "Everyone says [belief]. The data says otherwise."

See `CAROUSEL_GUIDE.md` for personalized hook examples and content ideas.

**Image prompt guidelines:**
1. Use the carousel prompt templates from `brand-visuals.md`:
   - Slide 1 → "Carousel Slide (Hook)" template
   - Middle slides → "Carousel Slide (Value)" template
   - Last slide → "Carousel Slide (CTA)" template
2. Fill in the text for each slide following the structure above.
3. If the content aligns with a pillar, add the pillar accent colors from `brand-visuals.md` Infographic Element Colors.
4. All slides: ivory background, warm charcoal text, infographic illustrations matching the slide content, brand handle bottom-center.
5. Consider mixing in 1-2 video clips for dwell time (mixed-media carousels hit 2.33% engagement).
6. Present all prompts to the user: **"Here are the image prompts for your [N]-slide carousel — approve or revise?"**
7. Generate each image using Gemini, then upload all to GHL Media Storage (see Step 5a).

**Multimodal carousel (images + video):**

If the user approved mixed media in Step 3b, use the multimodal generation pipeline:

1. Create a JSON config defining each slide's type, prompt, and settings.
2. Run `gen_multimodal_slides.py` which generates all images first (Gemini 3.1 Flash Image), then videos (Veo 3.1).
3. Video slides use either text-to-video (for hook slide) or image-to-video (animate an existing slide).
4. If a video fails, the script auto-falls back to a generated image with a warning.
5. Output: JSON manifest with file paths, types, and sizes.

```bash
python3 scripts/gen_multimodal_slides.py \
  --config /tmp/carousel_config.json \
  --output-dir /tmp/carousel_output
```

**Video generation config:**
- Model: `veo-3.1-generate-preview` (Veo 3.1)
- Duration: 4-6 seconds (4s for hooks, 6s for re-engagement)
- Aspect ratio: 9:16 portrait (matches IG feed autoplay)
- Resolution: 1080p
- Negative prompt: "cartoon, low quality, blurry, dark background, neon, stock footage, jarring transitions"
- Generation time: 60-360 seconds per video (async polling)

**Upload mixed media:**
```bash
bash scripts/ghl_upload_carousel.sh \
  --file /tmp/carousel_output/slide_01.mp4 \
  --file /tmp/carousel_output/slide_02.jpg \
  --file /tmp/carousel_output/slide_03.jpg \
  --platform ig --multimodal
```
With `--multimodal`, the script outputs a JSON manifest with URL+type pairs instead of comma-separated URLs.

**Platform-specific media handling:**
- **Instagram/Threads:** Use full mixed media array (images + videos).
- **Facebook:** Strip video URLs, use image-only media array.
- When posting to "All" platforms, build two media arrays: mixed for IG/TH, image-only for FB.

If the user provides image URLs, skip generation and go to Step 5a with `hosted: true`.

### Step 4b — Visual QA (Automated Review)

After generating all visuals (images and/or videos), run an automated quality check before uploading. Use Gemini's vision capabilities to evaluate each generated slide.

**What to check:**

1. **Text accuracy** — Read every word on the slide. Compare against the approved slide copy from Step 4. Flag any:
   - Misspelled words
   - Missing words or extra words
   - Wrong words (e.g., "form" instead of "from")
   - Garbled or unreadable text (common with AI image generation)
   - Text cut off by edges or overlapping elements

2. **Brand consistency** — Verify each slide matches the visual identity from `brand-visuals.md`:
   - Background is ivory (#f7f4ef) or warm linen (#f0ece4), not white or off-brand
   - Text color is warm charcoal (#3a352e), not black or gray
   - Accent colors match the content pillar (AI=gold, Leadership=sage, Sustainability=blush, Consciousness=lavender)
   - Typography looks clean and readable (no tiny text, no overlapping lines)

3. **Layout issues** — Check for:
   - Text overlapping icons or illustrations
   - Elements too close to the edges (minimum 80px margin)
   - Uneven spacing or misaligned elements
   - Empty areas where content should be

4. **Carousel consistency** — For multi-slide carousels, verify:
   - All slides share the same visual style (colors, layout structure, font sizes)
   - Slide numbering is correct and sequential
   - Brand handle is visible on each slide
   - No duplicate slides

**QA process:**

1. Read each generated image using the `Read` tool (which supports image files).
2. For each slide, compare the visible text against the intended copy. List every discrepancy.
3. Score each slide: **PASS** (no issues) or **FAIL** (has issues).
4. If ALL slides pass, proceed to Step 5a.
5. If ANY slide fails:
   a. Report the issues: **"Slide [N] has issues: [list]. Regenerating..."**
   b. Regenerate only the failed slides with a corrected prompt that emphasizes the misspelled/missing text.
   c. Re-run QA on the regenerated slides.
   d. Repeat up to 2 regeneration attempts per slide. After 2 failures, present the best version to the user: **"Slide [N] still has [issue] after 2 attempts. Use this version or provide a manual fix?"**

**For video slides:** Check the first frame only (read the video thumbnail or first-frame screenshot). Text accuracy is less critical for motion, but verify the visual style matches.

**Summary output:**
```
Visual QA Results:
  Slide 1 (Hook):  PASS
  Slide 2 (Value): FAIL — "Discernement" should be "Discernment"  → Regenerating
  Slide 3 (Value): PASS
  ...
  Slide 10 (CTA):  PASS

Regenerating 1 slide...
```

After all slides pass (or user accepts remaining issues), proceed to Step 5a.

### Step 5a — Upload Media to GHL

**Endpoint:** `POST https://services.leadconnectorhq.com/medias/upload-file`

**Headers:**
```
Authorization: Bearer $GHL_API_KEY
Version: $GHL_VERSION
```

**Body (multipart/form-data):**

| Field    | Type    | Required                        | Description                        |
| -------- | ------- | ------------------------------- | ---------------------------------- |
| `file`   | binary  | Yes (if `hosted` is false)      | The file to upload (max 25 MB, video 500 MB) |
| `hosted` | boolean | No                              | Set `true` if using external URL   |
| `fileUrl`| string  | Yes (if `hosted` is true)       | External URL of the file           |
| `name`   | string  | No                              | Display name for the media         |

**Example (hosted URL):**
```bash
curl -X POST "https://services.leadconnectorhq.com/medias/upload-file" \
  -H "Authorization: Bearer $GHL_API_KEY" \
  -H "Version: $GHL_VERSION" \
  -F "hosted=true" \
  -F "fileUrl=https://example.com/image.png" \
  -F "name=post-image-$(date +%Y%m%d)"
```

**Example (local file):**
```bash
curl -X POST "https://services.leadconnectorhq.com/medias/upload-file" \
  -H "Authorization: Bearer $GHL_API_KEY" \
  -H "Version: $GHL_VERSION" \
  -F "file=@/path/to/image.png" \
  -F "name=post-image-$(date +%Y%m%d)"
```

Capture the returned `url` from the response for use in Step 7.

**For carousels:** upload each slide image separately, collecting all returned URLs. Use `ghl_upload_carousel.sh` for batch uploads:
```bash
bash ghl_upload_carousel.sh \
  --url "https://example.com/slide1.png" \
  --url "https://example.com/slide2.png" \
  --url "https://example.com/slide3.png" \
  --platform ig
```
This validates slide count against the platform max and outputs comma-separated media URLs.

### Step 6 — Calculate "Next Free Slot"

Since GHL has no native "next slot" feature, implement timeline logic:

1. **Read** `ghl_post_log.md` to find the most recent `scheduledAt` timestamp.
2. **Default** the new post's `publishDate` to **24 hours after** the last logged timestamp.
3. If the log is empty, default to **tomorrow at 10:00 AM** in the user's local timezone.
4. Present the proposed date/time: **"I'll schedule this for [date/time]. Change?"**

### Step 7 — Publish to GHL

**Endpoint:** `POST https://services.leadconnectorhq.com/social-media-posting/$GHL_LOCATION_ID/posts`

**Headers:**
```
Authorization: Bearer $GHL_API_KEY
Version: $GHL_VERSION
Content-Type: application/json
```

**Request Body (single image):**
```json
{
  "accountIds": ["<socialMediaAccountId>"],
  "summary": "<platform-specific caption text>",
  "media": [
    {
      "url": "<media URL from Step 5a>",
      "type": "image"
    }
  ],
  "status": "scheduled",
  "scheduledAt": "<ISO 8601 datetime, e.g. 2026-02-20T10:00:00Z>",
  "tags": ["tag1", "tag2"]
}
```

**Request Body (carousel — multiple images):**
```json
{
  "accountIds": ["<socialMediaAccountId>"],
  "summary": "<caption for the entire carousel>",
  "media": [
    { "url": "<slide 1 URL>", "type": "image" },
    { "url": "<slide 2 URL>", "type": "image" },
    { "url": "<slide 3 URL>", "type": "image" }
  ],
  "status": "scheduled",
  "scheduledAt": "<ISO 8601 datetime>"
}
```

**Request Body (mixed-media carousel — images + video):**
```json
{
  "accountIds": ["<instagramAccountId>"],
  "summary": "<caption>",
  "media": [
    { "url": "<video slide 1 URL>", "type": "video/mp4" },
    { "url": "<image slide 2 URL>", "type": "image/jpeg" },
    { "url": "<image slide 3 URL>", "type": "image/jpeg" },
    { "url": "<image slide 4 URL>", "type": "image/jpeg" },
    { "url": "<video slide 5 URL>", "type": "video/mp4" },
    { "url": "<image slide 6 URL>", "type": "image/jpeg" }
  ],
  "status": "scheduled",
  "scheduledAt": "<ISO 8601 datetime>"
}
```

For **text-only** posts, omit the `media` array entirely.

**LinkedIn PDF carousel:** Upload the PDF via `/medias/upload-file` first, then pass it as a single media item with `"type": "document"`.

**Example curl:**
```bash
curl -X POST "https://services.leadconnectorhq.com/social-media-posting/$GHL_LOCATION_ID/posts" \
  -H "Authorization: Bearer $GHL_API_KEY" \
  -H "Version: $GHL_VERSION" \
  -H "Content-Type: application/json" \
  -d '{
    "accountIds": ["'"$ACCOUNT_ID"'"],
    "summary": "Your caption here...",
    "media": [{"url": "https://...","type": "image"}],
    "status": "scheduled",
    "scheduledAt": "2026-02-20T10:00:00Z"
  }'
```

**Response codes:**
| Code | Meaning              |
| ---- | -------------------- |
| 201  | Post created         |
| 400  | Bad request          |
| 401  | Unauthorized / token expired |
| 422  | Unprocessable entity |

### Step 8 — Log the Post

After a **201** response, append to `ghl_post_log.md`:

```
| <Platform> | <Scheduled DateTime> | <GHL Post ID> | <Status> |
```

Format example:
```markdown

```

Confirm to the user: **"Scheduled for [platform] on [date/time]. Post ID: [id]."**

## Error Resilience

If the GHL API returns an error:

### Token Expired (401)
- Notify: "Your GHL token appears expired. Please update `GHL_API_KEY` in `.claude/settings.local.json`."

### Media Type Not Supported (400/422)
1. **Fallback:** Re-submit the post as text-only (remove `media` array).
2. Notify: "GHL rejected the image format. I've adjusted to a text-only post to keep your 24-hour schedule."
3. Log the fallback in `ghl_post_log.md` with status `text-fallback`.

### Rate Limited (429)
- Wait 10 seconds, retry once.
- If still failing, notify: "GHL rate limit hit. Try again in a few minutes."

### Unknown Error
- Print the full error response for the user.
- Do NOT retry blindly — ask the user how to proceed.

## Carousel Reference

Carousels are created by passing multiple objects in the `media` array. No special `type: "carousel"` field is needed.

### Platform Support

| Platform  | Carousel? | Max Slides (GHL) | Recommended Dimensions | Aspect Ratio | Notes |
| --------- | --------- | ----------------- | ---------------------- | ------------ | ----- |
| Instagram | YES       | 10                | 1080 x 1350 px        | 4:5 (all slides must match) | Native supports 20, GHL caps at 10 |
| Facebook  | YES       | 10                | 1080 x 1080 px        | 1:1 (all slides must match) | Organic multi-image posts |
| LinkedIn  | YES (PDF) | N/A               | 1080 x 1350 px        | 4:5           | Upload PDF, auto-converts to swipeable carousel. Max 100 MB / 300 pages |
| TikTok    | YES       | 35                | 1080 x 1920 px        | 9:16          | Photo Mode carousel. GHL support may need LeadConnector mobile app |
| X         | NO        | 4 (multi-image)   | 1200 x 675 px         | 16:9          | Multi-image tweet, not a true carousel |
| GMB       | NO        | 1                 | —                      | —             | Single image only |
| Threads   | YES       | 20 images / 5 videos | 1080 x 1350 px     | 4:5           | Text-first. Supports mixed media (images + videos). |

### Carousel Design Rules (research-backed)

1. **8-10 slides** is the sweet spot. Use 12-20 for deep guides only. Every slide needs a purpose.
2. **4:5 portrait (1080 x 1350 px).** Takes up more screen on mobile. First slide's aspect ratio locks all others.
3. **Visual consistency.** Same colors, fonts, layout across all slides. Brand recognition before anyone reads.
4. **One idea per slide.** White space is your friend. People scan, not read paragraphs.
5. **Bold, readable text.** Large font, high contrast. Center text (top/bottom overlap with UI).
6. **Brand watermark** on each slide. When screenshots get shared, attribution travels with them.
7. **Mix media opportunity.** Adding 1-2 video clips spikes dwell time. Mixed-media carousels hit 2.33% engagement, but only 7% of carousels do this.
8. **Algorithm behavior:** If someone scrolls past without swiping, Instagram re-shows starting from slide 2. Each unswiped slide counts as "new content." No other format gets this second chance.
9. **Saves > Likes.** Carousels earn the highest save rate (0.55%). The algorithm weights saves over likes. DM shares are the strongest signal for new audiences.

See `CAROUSEL_GUIDE.md` for the full research, hook examples, content ideas, and Facebook-specific notes.

### LinkedIn PDF Carousel Workflow

LinkedIn carousels work differently. Instead of multiple images, you upload a single PDF:

1. Create slides as images (1080 x 1350 px, 4:5 ratio).
2. Combine them into a single PDF.
3. Upload the PDF via `POST /medias/upload-file`.
4. Pass the returned URL in the `media` array with `"type": "document"`.

```json
{
  "accountIds": ["<linkedinAccountId>"],
  "summary": "<caption>",
  "media": [
    { "url": "<pdf-url-from-upload>", "type": "document" }
  ],
  "status": "scheduled",
  "scheduledAt": "<ISO 8601>"
}
```
