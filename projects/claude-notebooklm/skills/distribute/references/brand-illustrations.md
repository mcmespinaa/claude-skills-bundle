# BRAND ILLUSTRATIONS & VISUAL ELEMENTS — Ces (Maria Cecilia)

> Part of the [Brand Kit](brand-kit.md) | v2.0

---

## Illustration Style

- Minimalist, infographic-style illustrations that match content topic
- Soft, organic, dimensional — never flat or sharp-edged
- Contextual: illustrations should visually represent the slide's message

### Stroke Style
- Fine lines: 0.5-1px
- Colors: Lavender (`#c4b8cc`) and Gold (`#d4c48e`) as default stroke colors
- Use pillar accent colors when content aligns to a specific pillar

### Surface Treatment
- Multi-color gradients blending 2-3 brand accent colors
- Subtle grain/noise texture overlay at 2-5% opacity
- Soft shadows and reflections for depth
- Muted gradient backgrounds (lavender-gray, blush-cream, or sage-ivory)

---

## 3D Gradient Shapes

Decorative shapes that appear as background accents, card elements, or hero decorations.

### Shape Rules
- Always soft, organic, rounded — no sharp corners or hard edges
- Appear as subtle background elements, never dominating the slide
- 1-2 shapes per slide maximum
- Apply grain texture overlay for consistency

### Shape Color by Pillar

| Pillar | Gradient flow |
|--------|--------------|
| AI + Product | Gold → cream → soft warm gray |
| Leadership | Sage → ivory → soft blue-gray |
| Sustainability | Blush → peach → soft teal |
| Consciousness | Lavender → blush → soft silver |

## Avatar Ring

Used on hook slides (Slide 1) and CTA slides.

| Property | Value |
|----------|-------|
| Shape | Concentric circle / ring |
| Gradient | Pillar-specific 3D gradient |
| Placement | Upper portion (hook) or centered (CTA) |
| Size | 80-120px diameter |

## Iconography Guidelines

When icons are needed (e.g., step indicators, feature lists):

| Property | Value |
|----------|-------|
| Style | Outlined, not filled |
| Stroke weight | 1-1.5px (matches illustration stroke) |
| Corner radius | Rounded (2-4px minimum) |
| Color | Pillar accent or `#7a7268` (secondary text) |
| Size | 24-32px for inline, 48-64px for featured |

---

## Spacing System

Use this scale for consistent spacing across all branded assets:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap |
| sm | 8px | Tag padding, tight grouping |
| md | 16px | Between related elements |
| lg | 24px | Between sections on a slide |
| xl | 32px | Major section breaks |
| 2xl | 48px | Top/bottom slide padding |
| 3xl | 64px | Hero spacing |
| 4xl | 80px | Minimum edge margin on carousel slides |

---

## What NOT to Use

- Flower of Life symbol
- Stock photos or generic clip art
- Flat, sharp-edged geometric shapes
- Heavy drop shadows or glossy effects
- Photorealistic renders or 3D humans
- Complex detailed illustrations (keep it minimal)
